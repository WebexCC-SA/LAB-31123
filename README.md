# LAB-31123 — Troubleshoot and Manage Your Organization with an AI Assistant

Web guide: [https://webexcc-sa.github.io/LAB-31123/](https://webexcc-sa.github.io/LAB-31123/)

Hands-on lab for WebexOne 2026. Participants build an AI assistant using Webex MCP servers, integrate it with a Webex Bot, and extend capabilities with a custom MCP server and Agent Skills.

## Local preview

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).
